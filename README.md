# EIOS｜能源数据分析与优化系统

EIOS 是一个面向综合能源系统的工程实践项目。当前基于 SimBench 公开电网基准数据，完成单日负荷数据筛选、质量检查、指标统计与可视化，并实现基于示例阈值的运行告警。

项目后续计划逐步加入数据库、负荷预测、电网潮流分析和储能优化等功能。

> 当前状态：V2 核心功能已实现，V3 待开发...

## 数据来源

当前使用 SimBench 的 `1-MV-comm--0-sw` 商业型中压配电网场景：

- 负荷数量：98 个
- 数据年份：2016 年
- 时间间隔：15 分钟
- 当前分析范围：选择数据中存在的一天

数据与工具来源：[SimBench 官方仓库](https://github.com/e2nIEE/simbench)  
许可信息：[SimBench 1.6.3 许可说明](https://github.com/e2nIEE/simbench/blob/v1.6.3/LICENSE)

## 当前功能

- 按日期筛选单日负荷数据；
- 检查必要字段、缺失值和重复记录；
- 检查一天的时间步及每个时间步的负荷编号数量；
- 汇总各时间步的总负荷；
- 计算最高、最低、平均负荷及峰谷差；
- 估算全天负荷电量；
- 导出汇总表并绘制负荷曲线。
- 使用 12 MW 示例阈值，识别总负荷达到或超过阈值的时间步；
- 导出告警时间、功率、阈值和超出量，并在日汇总中记录触发数量；
- 在负荷曲线上展示阈值线和告警点；
- 使用日志记录分析过程、规则触发和部分数据错误。

## 数据处理流程

```text
SimBench 基准网络
       ↓
读取并筛选目标日期
       ↓
导出负荷明细并检查数据质量
       ↓
计算负荷指标和估算电量
       ↓
生成汇总表与负荷曲线
       ↓
识别阈值告警
       ↓
统计指标并输出结果
```

## 运行方法

需要 Python 3.11。以下命令适用于 macOS 和 Linux，请在项目根目录运行：

```bash
# 创建并启用虚拟环境
python3.11 -m venv .venv
source .venv/bin/activate

# 安装依赖
python -m pip install -r requirements.txt

# 分析指定日期
python run_all.py 2016-12-01
```

可以将日期替换为数据中存在的其他日期，格式为 `YYYY-MM-DD`。不输入日期时，程序使用 `main.py` 中设置的默认日期。

运行异常数据检查示例：

```bash
python check_quality_demo.py
```

## 主要输出

| 文件 | 内容 |
|---|---|
| `load_example.csv` | 第一个负荷的全年数据示例 |
| `load_selected_day.csv` | 选中日期各负荷的明细数据 |
| `daily_total_load.csv` | 选中日期每个时间步的总负荷 |
| `daily_load_summary.csv` | 选中日期的指标汇总，包括告警阈值和触发数量 |
| `daily_load_curve.png` | 选中日期的总负荷曲线 |
| `load_alerts.csv` | 达到示例阈值的时间、功率、阈值、超出量和原因 |
| `eios.log` | 分析过程、规则触发及部分错误日志 |


重复运行会重新生成同名输出文件。

## 示例结果

分析 `2016-12-01` 时：

| 指标 | 结果 |
|---|---:|
| 最高总负荷 | 约 13.35 MW，10:45 |
| 最低总负荷 | 约 3.66 MW，01:45 |
| 平均总负荷 | 约 8.54 MW |
| 估算负荷总电量 | 约 205.04 MWh |
| 示例告警阈值 | 12 MW |
| 触发时间步 | 15 个 |
| 最大超出示例阈值 | 约 1.353 MW |
注意：12 MW 为演示用阈值。
电量按每个时间步的功率代表对应 15 分钟区间的功率进行估算。该结果是负荷侧的估算电量，并非企业实际计量值。

## 项目文件

- `main.py`：读取 SimBench 数据并整理目标日期的负荷明细；
- `data_quality.py`：提供数据质量检查函数；
- `inspect_data.py`：检查数据、统计指标并绘图；
- `run_all.py`：按顺序运行数据准备与分析流程；
- `check_quality_demo.py`：使用示例数据检查异常情况；
- `requirements.txt`：记录项目运行环境中的 Python 依赖。
